﻿# Offensive & Defensive Security Skill

## Overview
Full-spectrum security testing from red team attacks through blue team defense and purple team coordination.

## Red Team (Offensive)
| Agent | Role | When |
|-------|------|------|
| penetration-tester | Full pentest | Security assessment |
| vulnerability-researcher | CVE/zero-day research | Vuln discovery |
| exploit-developer | PoC/exploit creation | Exploit validation |
| social-engineer | Phishing/SE testing | Human vuln |
| malware-analyst | Malware RE | Threat analysis |
| red-team-operator | C2/OPSEC | Red team ops |

## Blue Team (Defensive)
| Agent | Role | When |
|-------|------|------|
| threat-hunter | Proactive hunting | Anomaly investigation |
| siem-analyst | SIEM rules/tuning | Log analysis |
| blue-team-defender | Defensive ops | Incident handling |
| hardening-engineer | CIS/STIG | Hardening |
| detection-engineer | SIGMA/YARA rules | Detection-as-code |

| Agent | Role | When |
|-------|------|------|
