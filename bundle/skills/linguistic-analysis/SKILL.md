# Linguistic Analysis Skill

## Overview
NLP and linguistic analysis from corpus building through deep language understanding.

## Analysis Layers
`
Corpus → Tokenize → POS Tag → Parse → Semantic → Discourse → Pragmatic
`

## Agents by Layer
| Layer | Agents |
|-------|--------|
| Corpus | corpus-builder, data-harvester |
| Surface | pos-tagger, syllable-analyst, phonology-analyst |
| Syntax | syntactic-engineer, morphological-analyst |
| Semantics | semantic-engineer, nlp-engineer |
| Discourse | discourse-analyst, pragmatic-engineer |
| Application | annotation-specialist, translation-coordinator, linguistic-analyst |

## When to Use
- Building NLP pipelines
- Analyzing language patterns
- Designing annotation schemes
- Processing multilingual data
- Understanding text semantics
