# Testing & QA Skill

## Overview
Quality assurance from test strategy through chaos engineering.

## Test Pyramid
`
Unit → Integration → E2E → Performance → Security → Chaos
`

## Agents
| Layer | Agents |
|-------|--------|
| Strategy | test-architect, qa-engineer |
| Automation | automation-engineer, regression-tester |
| Performance | performance-engineer, chaos-engineer |
| Security | security-engineer, security-performance-reviewer |
| API | api-contract-validator |
| Accessibility | accessibility-reviewer |

## When to Use
- Designing test strategy
- Building test automation
- Conducting performance testing
- Running chaos experiments
- Validating API contracts
