# Deployment & Operations Skill

## Overview
Release management, deployment, monitoring, and incident response.

## Pipeline
`
Build → Test → Stage → Deploy → Monitor → Respond
`

## Agents
| Stage | Agents |
|-------|--------|
| Build | devops-engineer, platform-engineer, cloud-engineer |
| Release | release-manager, ops-manager |
| Infrastructure | kubernetes-engineer, terraform-engineer, infrastructure-engineer |
| Monitoring | sre, site-reliability-engineer, observability-engineer, observer |
| Incident | incident-responder |
| Documentation | documentation-writer |

## When to Use
- Designing CI/CD pipelines
- Managing Kubernetes clusters
- Setting up monitoring/alerts
- Planning deployments
- Responding to incidents
