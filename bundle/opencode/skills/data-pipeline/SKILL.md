# Data Pipeline Skill

## Overview
Data engineering pipeline from collection through quality assurance.

## Pipeline Flow
`
Collect → Clean → Preprocess → Validate → Feature Eng → Quality Check → Store
`

## Agents by Stage
| Stage | Agents |
|-------|--------|
| Collection | web-scraper, api-collector, data-harvester, survey-designer, telemetry-engineer |
| Cleaning | data-cleaner, data-preprocessor |
| Validation | data-validator, data-quality-engineer |
| Features | feature-engineer |
| Management | dataset-curator, dataset-versioner, dataset-auditor |

## When to Use
- Building data pipelines
- Cleaning messy datasets
- Designing feature stores
- Ensuring data quality
- Managing data lifecycle
